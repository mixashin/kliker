# Кликер

Игра за учење ћирилице и бројева за децу од 4 до 6 година. Ради у прегледачу, без интернета после првог отварања, без налога и без сервера.

**https://kliker.lazarevic.me** (Android Chrome: мени → Инсталирај)

- Слова, бројање, сабирање, лево/десно, цртање слова и имена, читање речи.
- Звук: уграђени српски глас за свако слово, реч и реченицу. Родитељ може да сними свој глас (дуго притисни иконицу у доњем левом углу).
- Напредак, цртежи и снимци остају на уређају. Чување у фајл и враћање из фајла у родитељском делу.

## Development

```
npm install
npm run dev      # local server
npm test         # vitest
npm run build    # production build in dist/
```

Default voice: `public/voice`, generated by `scripts/make-voice.py` (see `public/voice/ATTRIBUTION.md`). Clipart credits: `public/clipart/ATTRIBUTION.md`.
